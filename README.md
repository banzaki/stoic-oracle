# Stoic Oracle

Converse with **Marcus Aurelius**, **Seneca** and **Epictetus** — AI portrayals grounded in their own writings, with every quotation checked against the library and traced to its source.

- **Three distinct voices.** The emperor writing to himself at night, the eloquent statesman who admits his contradictions, the blunt freedman of the schoolroom. Each has a permanent character and convictions that do not bend to flattery or provocation.
- **Grounded in the texts.** Every reply is built on passages retrieved from public-domain translations of the philosopher's own works, cited as numbered footnotes with the full passage underneath.
- **Authentic vs. interpretive, visibly.** Quotations found word for word in the cited passage are shown in gold with ✓; quotations attributed to the library that do not match are marked ≈ as paraphrase. Everything else is labelled as AI portrayal.
- **The Council of the Stoa.** Put one question to all three: they answer in turn, hear one another, and disagree where they genuinely would.
- **Any language.** The interface is English; the philosophers answer in the language you write in. Questions in other languages are translated into an English search query so retrieval still finds the right passages.

> **About the portrayals.** The philosophers' replies are generated by an AI model and are interpretations, not their literal words. The portraits are AI-generated artistic interpretations, not historical likenesses.

## Stack

- [Next.js 16](https://nextjs.org) (App Router, Turbopack), React 19, TypeScript, Tailwind CSS 4
- [Claude API](https://platform.claude.com) via `@anthropic-ai/sdk`: `claude-sonnet-5-5` (effort `low`) for the conversations; `claude-haiku-4-5` only to rewrite non-English questions as English search queries
- Local BM25 retrieval over corpora extracted from EPUBs — no vector database, no external search service

## Running locally

Requires Node.js 20+ and an Anthropic API key.

```bash
npm install
cp .env.example .env.local   # then put your key in ANTHROPIC_API_KEY
npm run dev
```

Open http://localhost:3000.

Without `ANTHROPIC_API_KEY` the site still opens, but the chat shows a "The oracle is silent" notice explaining how to configure the key. No reply is ever simulated. The key is read only by the server routes (`src/app/api/`); it is never sent to the browser.

## How it works

1. **Library → corpus.** `npm run corpus` reads the EPUBs in `library/` (read-only) and writes one JSON corpus per philosopher in `data/corpus/`. Translator footnotes, introductions, illustration captions and indexes are removed, since they are not the philosophers' words.

   | Philosopher | Works | Translation | Reference format | Passages |
   | --- | --- | --- | --- | --- |
   | Marcus Aurelius | Meditations | George Long | `Meditations IV.3` | 520 |
   | Epictetus | Enchiridion, Discourses (selection), Golden Sayings, Fragments | George Long, Hastings Crossley | `Enchiridion 5` | 573 |
   | Seneca | Moral Letters to Lucilius | Richard M. Gummere | `Moral Letters 1.3` | 1,061 |
   | | Dialogues, On Clemency, On Benefits | Aubrey Stewart | `On the Shortness of Life, ch. 3`, `On Benefits IV.12` | 1,213 |

   References name the work and its section rather than a page, because page numbers differ between editions.

2. **Retrieval.** `src/lib/retrieval.ts` ranks passages with BM25, with a small map from modern words to the vocabulary of 19th-century translators. Non-English questions are first rewritten as English queries (`src/lib/search-query.ts`).

3. **Generation.** `src/app/api/chat/route.ts` sends the philosopher's persona (`src/lib/personas/`), the conversation and the retrieved passages to Claude and streams the reply back as newline-delimited JSON. The persona is prompt-cached. Model fallback is deliberately disabled while the model is being evaluated.

4. **Verification.** In the browser, `src/lib/quotes.ts` checks every quotation against the passages and turns citations such as `[ench-5]` into footnotes. Translators and editions appear under *About this source* on each passage and on the [Sources](src/app/sources/page.tsx) page.

5. **Council.** `src/app/api/council/route.ts` lets the three speak in turn on one question; each receives the transcript so far plus passages from their own works only. The speaking order rotates each round.

## Library and licences

`library/` contains EPUBs of public-domain texts, treated as read-only source material, and `data/corpus/` holds passages extracted from them verbatim.

- **Project Gutenberg** editions (Long, Crossley, Stewart; Arnold and Stock): public domain in the USA, distributed unmodified with the Project Gutenberg licence inside each EPUB.
- **Wikisource** edition of Seneca's *Moral Letters to Lucilius*, translated by Richard M. Gummere (Loeb Classical Library, 1917–1925): the translation is in the public domain; the Wikisource digital edition is available under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/), courtesy of the contributors to [en.wikisource.org/wiki/Moral_letters_to_Lucilius](https://en.wikisource.org/wiki/Moral_letters_to_Lucilius).

Arnold's *Roman Stoicism* and Stock's *A Guide to Stoicism* are kept for reference and not used for retrieval. The portraits in `public/portraits/` are AI-generated images made for this project.
