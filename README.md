# Stoic Oracle

Converse with **Marcus Aurelius**, **Seneca** and **Epictetus** — AI portrayals grounded in their own writings, with every quotation checked against the library and traced to its source.

- **Three distinct voices.** The emperor writing to himself at night, the eloquent statesman who admits his contradictions, the blunt freedman of the schoolroom. Each has a permanent character and convictions that do not bend to flattery or provocation.
- **Grounded in the texts.** Every reply is built on passages retrieved from public-domain translations of the philosopher's own works, cited as numbered footnotes with the full passage underneath.
- **Authentic vs. interpretive, visibly.** Quotations found word for word in the cited passage are shown in gold with ✓; quotations attributed to the library that do not match are marked ≈ as paraphrase. Everything else is labelled as AI portrayal.
- **The Council of the Stoa.** Put one question to two or all three, in the speaking order you choose: they answer in turn, hear one another, and agree, build on each other or disagree only where they genuinely would.
- **Any language.** The interface is English; the philosophers answer in the language you write in. Questions in other languages are translated into an English search query so retrieval still finds the right passages. Quotations are then shown in your language: the English original is verified first, and the translation is marked as an AI translation, with the original one click away.
- **Sources on demand.** Each reply ends with a single line such as *2 references*; opening it shows the cited passages, then those only consulted, with full text, translator and edition.
- **Conversations you keep.** Conversations survive a reload (stored only in your browser), can be downloaded as Markdown, and any reply can be copied or shared as an image card.

> **About the portrayals.** The philosophers' replies are generated by an AI model and are interpretations, not their literal words. The portraits are AI-generated artistic interpretations, not historical likenesses.

## Stack

- [Next.js 16](https://nextjs.org) (App Router, Turbopack), React 19, TypeScript, Tailwind CSS 4
- [Claude API](https://platform.claude.com) via `@anthropic-ai/sdk`: `claude-sonnet-5-5` (effort `low`) for the conversations and for translating passages when a visitor opens them; `claude-haiku-4-5` for the quick steps of retrieval (rewriting non-English questions as English queries, naming their language, and re-ranking candidate passages by meaning)
- Two-stage retrieval over corpora extracted from EPUBs: local BM25 keyword search, then semantic re-ranking — no vector database, no external search service

## Running locally

Requires Node.js 20+ and an Anthropic API key.

```bash
npm install
cp .env.example .env.local   # then put your key in ANTHROPIC_API_KEY
npm run dev
```

Open http://localhost:3000.

To limit spending on a public deployment, the server keeps a daily budget (`DAILY_BUDGET_USD`, default US$2, estimated from token usage) and a per-visitor allowance (`REPLIES_PER_VISITOR_HOUR`, default 30); see `.env.example`. The counters live in the server's memory, so on serverless hosting they should move to a shared store, and a monthly spend limit in the Anthropic Console should be set as the hard ceiling.

Without `ANTHROPIC_API_KEY` the site still opens, but the chat shows a "The oracle is silent" notice explaining how to configure the key. No reply is ever simulated. The key is read only by the server routes (`src/app/api/`); it is never sent to the browser.

## How it works

1. **Library → corpus.** `npm run corpus` reads the EPUBs in `library/` (read-only) and writes one JSON corpus per philosopher in `data/corpus/`. Translator footnotes, introductions, illustration captions and indexes are removed, since they are not the philosophers' words.

   | Philosopher | Works | Translation | Reference format | Passages |
   | --- | --- | --- | --- | --- |
   | Marcus Aurelius | Meditations | George Long | `Meditations IV.3` | 520 |
   | Epictetus | Discourses (complete), Enchiridion, Golden Sayings, Fragments | George Long, Hastings Crossley | `Discourses III.22`, `Enchiridion 5` | 920 |
   | Seneca | Moral Letters to Lucilius | Richard M. Gummere | `Moral Letters 1.3` | 1,061 |
   | | Dialogues, On Clemency, On Benefits | Aubrey Stewart | `On the Shortness of Life, ch. 3`, `On Benefits IV.12` | 1,213 |

   References name the work and its section rather than a page, because page numbers differ between editions.

2. **Retrieval.** `src/lib/retrieval.ts` ranks passages with BM25, with a small map from modern words to the vocabulary of 19th-century translators. Non-English questions are first rewritten as English queries (`src/lib/search-query.ts`). About 20 keyword candidates per philosopher are then re-ranked by meaning in one quick call (`src/lib/rerank.ts`), which finds the passage that answers "I feel empty" even when it shares no word with it; if that step fails, the keyword order is kept.

3. **Generation.** `src/app/api/chat/route.ts` sends the philosopher's persona (`src/lib/personas/`), the conversation and the retrieved passages to Claude and streams the reply back as newline-delimited JSON. The persona is prompt-cached. Model fallback is deliberately disabled while the model is being evaluated.

4. **Verification.** In the browser, `src/lib/quotes.ts` checks every quotation against the passages and turns citations such as `[ench-5]` into footnotes. In other languages the philosopher writes `"translation" [ench-5 | exact English]`: the English is what gets verified, and the translation is shown with a *tr.* mark. Passages in the references are translated on demand by `src/app/api/translate/route.ts` and cached. Translators and editions appear under *About this source* on each passage and on the [Sources](src/app/sources/page.tsx) page.

5. **Council.** `src/app/api/council/route.ts` lets the chosen philosophers speak in the chosen order; each receives the transcript so far (with their own lines marked) plus passages from their own works only.

## Library and licences

`library/` contains EPUBs of public-domain texts, treated as read-only source material, and `data/corpus/` holds passages extracted from them verbatim.

- **Project Gutenberg** editions (Long, Crossley, Stewart; Arnold and Stock): public domain in the USA, distributed unmodified with the Project Gutenberg licence inside each EPUB.
- **Standard Ebooks** edition of Epictetus' complete *Discourses* in George Long's translation: public domain in the USA, with Standard Ebooks' own contributions dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
- **Wikisource** edition of Seneca's *Moral Letters to Lucilius*, translated by Richard M. Gummere (Loeb Classical Library, 1917–1925): the translation is in the public domain; the Wikisource digital edition is available under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/), courtesy of the contributors to [en.wikisource.org/wiki/Moral_letters_to_Lucilius](https://en.wikisource.org/wiki/Moral_letters_to_Lucilius).

Arnold's *Roman Stoicism* and Stock's *A Guide to Stoicism* are kept for reference and not used for retrieval. The Enchiridion is still read from Long's Gutenberg selection volume, whose Discourses selection is now superseded by the complete edition. The portraits in `public/portraits/` are AI-generated images made for this project.
